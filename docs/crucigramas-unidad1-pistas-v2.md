# Crucigramas — Unidad 1 (pistas reescritas)

Propuesta de pistas y explicaciones para los 7 crucigramas de la Unidad 1.
**Solo cambian los textos** (`clue`, `explanation`, y en un caso el `prompt`). Respuestas, posiciones,
direcciones y bancos de distractores se mantienen iguales, salvo la sugerencia sobre `HONESTIDAD`
en la sección de notas.

## Criterios aplicados

- Tono: lenguaje académico (se conservan los términos del tema) con redacción cercana al estudiante.
- Una pista = un concepto, con la misma categoría gramatical que la respuesta.
- La pista **no** contiene la respuesta, sus derivados ni palabras del banco de distractores.
- Ejercicios: definiciones cortas, completar la frase y ejemplos concretos.
- Evaluaciones: **escenarios** distintos a los de los ejercicios, para medir comprensión y no memoria.
- La longitud `(n)` no está escrita en las pistas: conviene que el componente la muestre con
  `answer.length` (ver notas).

## 1. `cross1.2` — Atributos del software (l1.2)

- **Prompt:** Crucigrama de atributos del software
- **Instrucciones:** Toca una celda y escribe la palabra que corresponde a la pista. Escribe sin tildes.

| Etiqueta | Respuesta | Pista nueva |
|---|---|---|
| H1 | ACEPTABILIDAD | Cualidad que hace al software comprensible, fácil de usar y compatible con otros sistemas; si falla, los usuarios lo rechazan. |
| V1 | CONFIABILIDAD | Cualidad por la que el sistema responde sin fallas y resiste ataques maliciosos: puedes contar con él. |
| V2 | EFICIENCIA | Atributo de un sistema que aprovecha bien la memoria y el procesador, sin malgastar ciclos. |
| V3 | INGENIERIA | ___ de software: disciplina que abarca todo el proceso de producción, desde la especificación hasta el mantenimiento. |

- **Explicación:** Aceptabilidad, confiabilidad y eficiencia son atributos de calidad que van más allá de lo que el sistema hace. La ingeniería de software es la disciplina que busca lograrlos a lo largo de todo el proceso.

## 2. `cross1.2a` — Atributos y tipos de software (l1.2)

- **Prompt:** Crucigrama: atributos y tipos de software *(antes: "conceptos del desarrollo profesional")*
- **Instrucciones:** Toca una celda y escribe la palabra que corresponde a la pista. Escribe sin tildes.

| Etiqueta | Respuesta | Pista nueva |
|---|---|---|
| H1 | MANTENIMIENTO | **Atributo**: facilidad para modificar el software cuando el cliente cambia sus necesidades. |
| V1 | EFICIENCIA | Atributo de un sistema que hace buen uso de la memoria y del procesador: no malgasta recursos. |
| H2 | GENERICO | Un procesador de textos es un producto ___: se desarrolla para venderlo a cualquier cliente del mercado. |
| V2 | EVOLUCION | **Actividad** de seguir cambiando un sistema ya entregado para que continúe siendo útil al negocio. |
| H3 | MEDIDA | Software personalizado: se desarrolla "a la ___" del cliente. |

- **Explicación:** Mantenimiento y eficiencia son atributos; genérico y "a la medida" son los dos tipos de producto; la evolución es la actividad que mantiene vivo al sistema después de entregarlo. Ojo con la diferencia: el mantenimiento es una *cualidad* del software y la evolución es algo que *se hace* con él.

## 3. `cross1.3` — Ética profesional (l1.3)

- **Prompt:** Crucigrama de ética profesional
- **Instrucciones:** Toca una celda y escribe la palabra que corresponde a la pista. Escribe sin tildes.
- **Banco (distractores):** `PRODUCTO`, `JUICIO`, `COLEGAS`, `HONESTIDAD`

| Etiqueta | Respuesta | Pista nueva |
|---|---|---|
| H1 | CONFIDENCIALIDAD | Deber de guardar reserva sobre la información del empleador o del cliente, aunque no hayas firmado ningún acuerdo. |
| V1 | COMPETENCIA | Deber de aceptar solo los trabajos para los que estás realmente capacitado. |
| V2 | INTEGRIDAD | Deber de actuar con rectitud y sin conflictos de interés; aceptar un soborno para elegir un proveedor lo viola. |
| V3 | ETICA | Conjunto de principios que orienta lo correcto en la conducta de un profesional. |

- **Explicación:** Confidencialidad, competencia e integridad son deberes centrales del código de ética profesional. La honestidad forma parte de la integridad, pero el deber completo es más amplio: incluye evitar conflictos de interés.

## 4. `cross1.4` — Estudios de caso (l1.4)

- **Prompt:** Crucigrama de estudios de caso
- **Instrucciones:** Toca una celda y escribe la palabra que corresponde a la pista. Escribe sin tildes.
- **Banco (distractores):** `SENSORES`, `PACIENTES`, `SATELITAL`, `PRIVACIDAD`

| Etiqueta | Respuesta | Pista nueva |
|---|---|---|
| H1 | METEOROLOGICA | Estación ___: opera a campo abierto y recoge datos del clima de forma automática. |
| V1 | MHC | Siglas del caso de estudio sobre atención de salud mental. |
| V2 | EMBEBIDO | Tipo de sistema cuyo software forma parte del hardware que controla. |
| V3 | INSULINA | Hormona que la bomba automática suministra a personas con diabetes. |

- **Explicación:** La estación meteorológica ejemplifica la adquisición de datos a campo abierto; la bomba de insulina, un sistema embebido; y MHC identifica el caso de salud mental, donde la privacidad de la información es clave.

## 5. `ev1.2` — Atributos (evaluación l1.2)

- **Prompt:** Completa el crucigrama de atributos
- **Banco (distractores):** `CONFIABILIDAD`, `SOFTWARE`, `USABILIDAD`

| Etiqueta | Respuesta | Pista nueva (escenario) |
|---|---|---|
| H1 | MANTENIMIENTO | Tu cliente cambia sus reglas de negocio y el sistema debe poder ajustarse sin rehacerse desde cero: ¿qué atributo lo permite? |
| V1 | ACEPTABILIDAD | Los usuarios no entienden la interfaz y el sistema no se integra con sus otras herramientas: falla este atributo. |
| V2 | EFICIENCIA | Una aplicación tarda varios segundos en responder y consume casi toda la memoria del equipo: falla este atributo. |

- **Explicación:** Cada escenario apunta a un atributo distinto: ajustarse al cambio es mantenimiento, ser comprensible y compatible es aceptabilidad, y aprovechar bien los recursos es eficiencia.

|---|---|---|

## Notas para la implementación

1. **Longitud en la pista:** mostrar `(${answer.length})` junto al texto de la pista en `CrosswordExercise.tsx`
   evita escribir los números a mano y que se desfasen si cambias una respuesta.
2. **Siglas:** `MHC` ya dice "Siglas" en la pista. Si hay más casos, se puede añadir un campo opcional `isAcronym`.
3. **Sin tildes:** el motor solo acepta `A-Z` y `Ñ`, así que conviene dejar la indicación "Escribe sin tildes"
   en las instrucciones de todos los crucigramas.
4. **Banco de `cross1.3`:** `HONESTIDAD` y `INTEGRIDAD` miden 10 letras y significan algo muy cercano.
   Aunque la pista ya no induce al error, considera reemplazar `HONESTIDAD` por un distractor de otra
   longitud o claramente distinto (por ejemplo `PRIVACIDAD` o `PROPIEDAD`), o dejarlo solo si quieres
   que sea una trampa deliberada.
5. **Evaluaciones vs. ejercicios:** las pistas de `ev1.x` usan escenarios y las de `cross1.x` definiciones o ejemplos,
   así que ya no se repite la misma redacción entre práctica y evaluación.
